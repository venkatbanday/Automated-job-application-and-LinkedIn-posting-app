# Changelog

## 1.1.0 — CareerOS integrated release

### Preserved from the supplied application
- Original CV/job description keyword comparison and job-search toolkit.
- Original Career Hub job stages, recruiter/contact tracking, outreach templates, LinkedIn profile helper, 9-step plan, CSV export and browser backup/restore.
- Original Resume Tailoring Tool with resume upload/paste, job description matching, tailoring, templates, editor, cover letter and interview preparation.
- Original LinkedIn Post Maker with AI drafting, post-image generation, banner creation and weekly content planning.

### Added and improved
- Unified dashboard with a live summary of Career Hub jobs, contacts, interviews, offers and follow-ups.
- Unified navigation and persistent light/dark theme across pages.
- Advanced Job Fit Analysis with evidence alignment, missing terms, user-defined essential criteria, risk flags, next steps, optional AI review and report export.
- Interview Coach with question bank, STAR builder, local completeness rubric, saved practice and optional AI evaluation.
- LinkedIn Carousel Studio with slide preview and PNG exports.
- Cross-tool JSON backup/restore utility, including local resume and LinkedIn draft records.
- Resume Studio local draft autosave and recovery controls (CV, job description and target role).
- LinkedIn Studio local content autosave and recovery controls (draft text and calendar content; API keys excluded).
- Career Hub edit controls for existing job and recruiter/contact records, plus confirmation before deletion.
- PWA manifest, app icon, service worker and offline static shell.
- GitHub Actions smoke-test workflow, documentation, release notes and MIT licence.
- Mobile-responsive navigation and skip-to-content accessibility link on the original tools.

### Notes
- No original app workflow was intentionally removed.
- Static browser storage remains local to each browser/device.
- AI features remain optional and require the user's own provider key.
