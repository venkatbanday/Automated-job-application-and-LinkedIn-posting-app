Privacy and responsible use

Your career records are stored in this browser. The optional AI tools send only the text needed for the action you select to the provider you choose. API keys are not saved by these new AI pages. Review provider terms and avoid confidential employer or client data.

Important

Keyword percentages and suitability indicators are decision-support aids, not employer ATS scores, hiring predictions or guarantees. Verify every generated statement and use only achievements you can substantiate.
